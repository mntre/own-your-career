  OKR SCORE CALCULATION — QUICK REFERENCE

FORMULA:
  Score = Sum of ((Actual Result / Target Result) * Weight) for all KRs

STEP-BY-STEP EXAMPLE:
  
  Given 2 Key Results:
  ┌─────────────────────────────────────────────────────────────────────────┐
  │ KR1: Actual=90, Target=100, Weight=40%                                  │
  │      Achievement = (90/100)*100 = 90%                                    │
  │      Contribution = (90*40)/100 = 36%                                    │
  │                                                                           │
  │ KR2: Actual=100, Target=100, Weight=60%                                 │
  │      Achievement = (100/100)*100 = 100%                                 │
  │      Contribution = (100*60)/100 = 60%                                   │
  │                                                                           │
  │ TOTAL SCORE = 36 + 60 = 96% ← ACHIEVED bracket                          │
  └─────────────────────────────────────────────────────────────────────────┘

PERFORMANCE BRACKETS:

  ≥101%        →  EXCEEDED (Top performer)
  90.1% - 100% →  ACHIEVED (Meeting expectations)
  81% - 90%    →  NEEDS_IMPROVEMENT (Below expectations)
  ≤80%         →  FAILED (Significantly below)

     │
     ├─ computeOKRHierarchy(groupKRs, deptKRs, teamKRs)
     │  └─ Hierarchy: calculates scores for all levels, cascades up
     │

     │  └─ Detail: generates breakdown with contributions
     │
     ├─ assignPerformanceBracket(finalScore)
     │  └─ Bracket: maps score to EXCEEDED/ACHIEVED/NEEDS_IMPROVEMENT/FAILED
     │
     └─ getBracketDisplay(bracket)
        └─ Display: returns label & CSS class for UI rendering

  2. src/frontend/html/dataspoc-portal.html
     ├─ calculateAndDisplayScores(level)
     │  └─ Real-time: updates scores as user enters actual results
     │
     ├─ displayOKRResults()

HOW TO TEST:

  1. Open Data SPOC Portal
  2. Upload OKR CSV file
  3. Select Corporate → Group → Department → Team
  4. Click "Generate OKR Form"
  5. Enter Actual Result values (e.g., 85)
     → Scores update real-time in score cells
  6. Click "Submit OKR Data"
     → Console shows: "=== OKR COMPUTATION RESULTS ==="
     → Results panel displays final scores & brackets
  7. Click on "Key Results Summary" table
     → See Actual %, Weight %, Contribution % for each KR

VALIDATION:

  ✓ All actual results must be filled (empty = 0)
  ✓ Non-numeric rejected during submission
  ✓ Division by zero protected (targetResult defaults to 1)
  ✓ Scores capped at 200% (extreme overachievement)
  ✓ Empty form arrays treated as 0 contribution
