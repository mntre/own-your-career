================================================================================
ENHANCED OKR TEMPLATE — 4-Level Hierarchy with DOWNWARD Cascade
================================================================================

OVERVIEW:
New CSV format supports complete OKR hierarchy:
  Corporate → Group → Department → Team
  
With DOWNWARD cascading fallback logic:
  - If Department is blank → Use Group OKR
  - If Team is blank → Use Department OKR (or Group if Department is blank)


================================================================================
CSV STRUCTURE
================================================================================

11 Required Columns (in exact order):

1.  Corporate              - Company/Converge entity
2.  Group                  - Business group (e.g., People Platforms)
3.  Group_Objective        - Group-level objective (REQUIRED - always provided)
4.  Group_KeyResult        - Group-level key result (REQUIRED - always provided)
5.  Department             - Functional department (e.g., Data Analytics)
6.  Department_Objective   - Department-specific objective (OPTIONAL - can be blank)
7.  Department_KeyResult   - Department-specific key result (OPTIONAL - can be blank)
8.  Team                   - Team within department (e.g., Data Analytics, Platforms)
9.  Team_Objective         - Team-specific objective (OPTIONAL - can be blank)
10. Team_KeyResult         - Team-specific key result (OPTIONAL - can be blank)
11. Weight                 - Percentage weight (0-100)


================================================================================
FALLBACK LOGIC (DOWNWARD CASCADE)
================================================================================

Cascade Direction: Group → Department → Team (DOWNWARD)

Priority Hierarchy:
  1. Group (BASE LEVEL - always provided - highest priority)
  2. Department (can be blank, inherits from Group)
  3. Team (can be blank, inherits from Department or Group)

Rule 1: Group_Objective / Group_KeyResult
├─ ALWAYS must be provided
└─ This is the BASE level

Rule 2: Department_Objective / Department_KeyResult blank?
├─ IF blank → Use Group_Objective / Group_KeyResult (INHERIT FROM GROUP)
├─ IF provided → Use Department values
└─ Department CAN override Group

Rule 3: Team_Objective / Team_KeyResult blank?
├─ IF blank → Use Department's (INHERIT FROM DEPARTMENT)
├─ IF Department is also blank → Use Group's (CASCADE THROUGH Department)
├─ IF provided → Use Team values
└─ Team CAN override Department or Group

Examples:

SCENARIO A: Group Only (Dept & Team blank)
  Group:      "Streamline hiring" / "Reduce time-to-hire"
  Department: "Streamline hiring" / "Reduce time-to-hire"  (inherited from Group)
  Team:       "Streamline hiring" / "Reduce time-to-hire"  (inherited from Group via Dept)

SCENARIO B: Group + Department (Team blank)
  Group:      "Build scalable systems" / "Deploy portal"
  Department: "Improve reporting" / "Deliver 12+ reports"  (provided, overrides Group)
  Team:       "Improve reporting" / "Deliver 12+ reports"  (inherited from Department)

SCENARIO C: All Levels (No inheritance needed)
  Group:      "Group objective" / "Group KR"
  Department: "Dept objective" / "Dept KR"
  Team:       "Team objective" / "Team KR"

================================================================================
WEIGHT DISTRIBUTION
================================================================================

Per Team/Department:
  - Weights should sum to ~100% (allow 1% tolerance)
  - Can be spread across multiple rows
  - Weight applies to OKR score calculation

Formula:
  OKR Score = Sum(Actual Result % × Weight) / 100

================================================================================
VALIDATION RULES
================================================================================

✓ ALLOWED BLANKS:
  - Department_Objective (will inherit from Group)
  - Department_KeyResult (will inherit from Group)
  - Team_Objective (will inherit from Department or Group)
  - Team_KeyResult (will inherit from Department or Group)

✗ NOT ALLOWED (Will cause error):
  - Corporate (must have value)
  - Group (must have value)
  - Group_Objective (REQUIRED - must have value)
  - Group_KeyResult (REQUIRED - must have value)
  - Department (must have value)
  - Team (must have value)
  - Weight (must be valid number)
