Employee Database Upload

Upload master employee list before review cycle

Upload a CSV file containing all employees who will participate in the mid-year performance review. This seeds the system with employee data, roles, and manager relationships.

Accepted CSV Format: SAP SuccessFactors HRMF Export

Upload the standard SAP employee file (HRMF Without Compensation). The system will map these columns automatically:

HR Business Partner, Employee No., Full Name, Last Name, First Name, Middle Name, Employment Status, Position Position Title, Band, Pathway (Code), Pathway (Label), Job Code (Code), Job Code (Label), Business Group (Code), Business Group (Label), Department (Code), Department (Label), Cost Center (Code), Cost Center (Label), Business Area, Immediate Supervisor, OT Approver, Assignment Code, Base of Assignment, Affiliate, Gender, Email Address
  • Employee No. → Employee ID
  • Full Name → Display Name
  • Email Address → Login Email
  • Business Group (Label) → Group
  • Department (Label) → Department
  • Band (Picklist Label) → Band/Level
  • Immediate Supervisor → Manager
  • Position Position Title (Label) → Job Title

Note: Role assignment (Manager, Data SPOC, Employee, Admin) is done separately after upload.
